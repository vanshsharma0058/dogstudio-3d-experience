## DogStudio-3D Website

## 🌍 Live Demo

👉 https://dogstudio-3d-experience.vercel.app/

## Overview

-DogStudio is a modern, interactive 3D website built using **React**, **Three.js**, **GSAP**, and **custom shaders**.  
-The project focuses on smooth scroll-based animations, immersive 3D models, and visually rich effects.

-This repository contains the source code for the DogStudio-3D website, which showcases our 3D modeling and animation services. The website is built using modern web technologies to provide an engaging user experience.

---

## 🚀 Tech Stack

- **React.js** – Component-based UI development
- **Three.js** – 3D rendering in the browser
- **@react-three/fiber** – React renderer for Three.js
- **@react-three/drei** – Useful helpers for Three.js
- **GSAP** – High-performance animations
- **ScrollTrigger** – Scroll-based animation control
- **Custom GLSL Shaders** – Advanced visual effects
- **Vite** – Fast development build tool

---

## ✨ Features

- Smooth scroll-based animations using GSAP + ScrollTrigger
- Interactive 3D dog model rendered with Three.js
- Custom shader materials for realistic and artistic effects
- Optimized performance with React Three Fiber
- Clean and modern UI inspired by creative studios
